# Documentos de Vehículos APK

Aplicación Android nativa en Java.

Incluye:
- Suzuki Baleno y Bajaj Dominar 250 como vehículos iniciales.
- Agregar, editar y eliminar vehículos.
- Cargar uno o varios PDF/JPG/PNG desde el teléfono.
- Renombrar y eliminar documentos.
- Abrir documentos con el visor disponible en Android.
- Modo claro/oscuro.

Los documentos se guardan como permisos persistentes de Android (Storage Access Framework).
